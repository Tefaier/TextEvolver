Text Evolver - this website allows you to alter content of your text-based files in certain ways

The way text will be altered is based on "setting" that you create and is connected yo your account


Name of setting: it's the way your setting will be named and viewed in "My settings" and when you search

Publicity of setting: determines if your setting can be founded by users in search

Clean empty of setting: determines if to clean lines without actual meaning (only symbols - no letters or digits) in the text

Convert to utf of setting: determines if to convert symbols as < to their utf representation

Digit separator: determines what will be recognised as a separator in decimals, only one can be chosen

Expect feet: if you want your setting to recognise ft in the form of 6'7, choose it. They will then be converted to cm by default unless you set unit convertation from phrase "feet"


Fandom of {name}: a recognition of certain fandom based on official website. User can't add a new one. Its function is to add images to text if it finds name from fandom

Fandom - Activated: determines if this fandom is activated. If yes, it can heavily affect performance speed

Fandom - Separation: determines number of words that have to be between the same phrase to trigger image insertion. If it's "1", it will insert image only once

Fandom - Show height: tells if image should have this value on it (taken from official website). Won't be shown if it's not possible

Fandom - Show weight: tells if image should have this value on it (taken from official website). Won't be shown if it's not possible


Unit convertation: recognises unit and then converts it to another

Unit - Initial unit: what word will be recognised and trigger change

Unit - New unit: the unit that unit will be replaced with

Unit - Convertation of unit: by what value number before unit will be multiplied

Unit - Can be word: if initial unit can be as well act as word and not unit, choose it. Otherwise it will always change and add number before it, if there is none


Image add (convertation): adds image based on some phrase

Image - Trigger phrase: what phrase will be recognised and trigger change (if it overlaps with fandom's value, they will merge)

Image - Separation: determines number of words that have to be between the same phrase to trigger image insertion. If it's "1", it will insert image only once

Image - Explanation: a phrase that will be added on image as a sort of explanation. Must be at most 64 characters. If left empty, there will be none (and no space on image reserved)

Image - Accept suffix: if recognition by phrase should accept having suffixes

Image - Images: image(s) that will be added. If there are few, one will be chosen randomly. If it's merged with fandom's value, image will be chosen from these and fandom's. Also, if you opened already existing setting, living it empty will leave previous images and changing will set new


Phrase convertion: recognises phrase and then converts it to another

Phrase - Change from: what phrase will be recognised and trigger change

Phrase - Change to: on what phrase initial one will be changed

Phrase - Direct change: if chosen, change will recognise only initial phrase as it's but will as well allow initial phrase to have special symbols

Phrase - Accept suffix: if recognition by phrase should accept having suffixes. If direct change is chosen, it's irrelevant


Put here files to process: files for process

Save - your settings only: saves settings

Save and run - your setting only: saves settings and then runs it on inputted files

Run: runs setting on inputted files

Copy - others setting only: will copy setting and add it to your own. Requires you to have free space for it. Publicity of copied setting will be set to private
